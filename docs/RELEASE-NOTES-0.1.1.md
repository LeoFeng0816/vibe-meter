# Vibe Meter v0.1.1

- 可指定選單列顯示的 agent 與週期，新增繁體中文、簡體中文和英文介面。
- Claude Code 透過官方狀態列 bridge 更新。打開面板或重新整理即刻重讀；bridge 以官方回應計數的單調高水位排除重播、亂序與其他工作階段的舊值，並以檔案鎖序列化寫入。15 分鐘沒有新資料會標示未更新。
- Claude Code 續作改由官方原生「Continue automatically at usage limit」（2.1.234 起）在原視窗處理。Vibe Meter 顯示能力、使用者設定檔的值、可觀察的中止與後續狀態及 `/config` 引導，不送出提示、不開新視窗、不修改 Claude 設定。
- Codex 每 30 秒只查詢官方唯讀額度（可關閉），打開面板即查詢；與刷新共用單一查詢，離線、睡眠、停用時暫停，失敗保留上次官方值並退避。
- Codex 預設自動續作，也可手動限定工作階段、帳戶與模型。自動送出需要能對應中止 turn 模型的官方額度桶、中止時段同帳戶的明確拒絕，以及重設後明確的一般用量許可。新增重啟後比對（每週額度可保留至重設後）、同工作階段新中止點取代舊計畫、送出前最近查詢可否決、跨程序單次送出及佇列回執狀態。
- 只有一般 `codex` 額度桶（`normalModelSlug` 為 null）的帳戶：依使用者明確要求，預設在官方重設時間＋30 秒對原工作階段嘗試一次（固定中性提示，不宣稱已恢復）。身分、時間與中止證據與官方路徑相同；許可為 null、帳戶不符、花費上限或 credits 用盡、歧義額度桶時不送。較晚的有效重設會持久化延期（最多 7 天）。每個工作階段以跨程序檔案鎖只嘗試一次，之後要等使用者手動繼續才再自動嘗試。關閉時仍可看逐項診斷並手動繼續。
- 修正 app-server 與 CLI 子程序等待可能卡住、30 秒查詢取消後並發排空崩潰、查詢失敗後舊值仍被當成即時依據等問題。
- 新增 Antigravity CLI 官方狀態列橋接。Desktop 使用 Settings › Models，Cursor 使用編輯器或官方儀表板。
- 可設定低額度通知門檻，管理通知權限，定時或在確認 Codex 正在工作時保持清醒。
- 可匿名檢查 GitHub 正式 release，並選擇驗證及下載 DMG。v0.1.1 內建發布者公鑰及 Sparkle，可在設定開啟預設關閉的自動安裝及重新啟動。v0.1.0 須先手動升級。後續自動更新須有可匿名取得的簽章 appcast 及 ZIP。

安裝包支援 Apple Silicon 上的 macOS 14 或以上，採 ad-hoc 簽章。Apple 公證尚待辦理。

新版 Vibe Meter 實例共用續作授權。設定撤銷與個別計畫取消在 Codex CLI 啟動前生效。Claude Code 仍由原視窗按官方機制續作。
